# Invariantes · Ensamblaje de cláusulas

1. Una cláusula es salida derivada, nunca punto de partida.
2. Toda cláusula debe poseer genealogía vertical hasta motivo/tareas/raíces.
3. Una cláusula sin raíces estructurales no alcanza SUPPORTED.
4. Una activación temporal no crea una cláusula.
5. Estado epistemológico y estado temporal son variables distintas.
6. INTEGRADA, TRANSFORMADA y CERRADA requieren hechos documentados.
7. La firma de cumplimiento se define antes de evaluar el hecho usado para comprobarla.
8. El solapamiento de cláusulas se controla para no duplicar evidencia.
9. Compuesta y Davison no generan independencia adicional por aparecer en dos cartas.
10. CLD8_UNIQUE_CLAUSE permanece NOT_VALIDATED.
11. ESSENTIAL significa centralidad estructural, no superioridad espiritual.
12. Cumplimiento de una cláusula no equivale a unión romántica.
13. Cierre no equivale necesariamente a separación.
14. La sombra no se confunde con la función contractual.
15. El relato final se redacta después de cerrar la matriz de cláusulas.
