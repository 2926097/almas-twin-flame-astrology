# Invariantes · Anclas documentales

1. Todo source_basis usado por un mapeo doctrina→astrología tiene verification_anchor y verification_anchor_type.
2. METADATA_ONLY no sostiene por sí solo una afirmación doctrinal detallada.
3. ABSTRACT no se usa para atribuir contenido ausente del resumen.
4. AUTHOR_SUMMARY describe el método/creencia del autor, no validación independiente.
5. PUBLISHER_SUMMARY no sustituye texto primario para reglas finas.
6. TABLE_OF_CONTENTS demuestra cobertura temática, no contenido detallado.
7. C_DOCTRINE exige una ancla primaria suficientemente precisa.
8. B_TECHNIQUE exige descripción técnica verificable; existencia bibliográfica no basta.
9. La precisión de la conclusión no supera la precisión del ancla.
10. La calidad del ancla nunca añade puntuación astrológica.
