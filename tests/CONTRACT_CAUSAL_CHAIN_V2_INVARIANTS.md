# Invariantes · Cadena causal del contrato preencarnatorio v2

1. ORIGIN no forma parte de la cadena contractual mínima.
2. C1 TAREA_PREVIA debe sobrevivir con la carta del otro retirada.
3. C2 MOTIVO_DE_ELECCION requiere adecuación específica del activador.
4. C3 ROL no puede derivarse de una identidad narrativa totalizante.
5. C4 ACTIVACION no equivale a cumplimiento.
6. C5 PRUEBA debe existir como tensión trazable, no como racionalización de un evento posterior.
7. C6 INTEGRACION se define antes de evaluar cumplimiento.
8. C7 CUMPLIMIENTO requiere firma preregistrada y hechos.
9. C8 CIERRE no equivale necesariamente a separación.
10. R4_CONTENIDO_LITERAL no puede alcanzar SUPPORTED desde astrología.
11. EVENT y DETAIL no pueden elevarse desde temporalidad aislada.
12. Toda frase narrativa contractual debe tener traza hacia C1–C8.
