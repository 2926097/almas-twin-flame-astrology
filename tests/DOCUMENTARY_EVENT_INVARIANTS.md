# Invariantes · Capa documental

1. Todo ledger referencia un análisis estructural congelado.
2. Un evento no crea raíces ni cláusulas.
3. Fact statement e interpretación se almacenan por separado.
4. No se inventan horas para cartas de evento.
5. Eventos futuros no se registran como hechos.
6. DQ5_UNVERIFIED nunca eleva una cláusula a SUPPORTED.
7. Viabilidad y reciprocidad real proceden de hechos, no de astrología.
8. GitHub no publica PRIVATE_AUTHORIZED ni PRIVATE_RESTRICTED.
9. Correcciones conservan trazabilidad mediante supersedes_event_id.
10. Un evento puede aportar contraevidencia y degradar una interpretación.
