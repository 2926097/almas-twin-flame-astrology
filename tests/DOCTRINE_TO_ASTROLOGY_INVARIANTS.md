# Invariantes · Doctrina a astrología

1. Ninguna fuente añade IEM/IAP/puntos por existir.
2. Todo mapeo doctrina→astrología declara operationalization_class.
3. Una técnica astrológica sólo es C_DOCTRINE si la propia fuente la prescribe explícitamente.
4. Kardec no se usa como fuente de nodos, Saturno o dracónica.
5. Luria no se usa como fuente de astrología dracónica.
6. Summit Lighthouse no se usa como fuente de aspectos astrológicos twin-flame.
7. Stokke documenta fenomenología; no crea scoring ontológico.
8. Crane documenta técnica dracónica; no prueba contratos.
9. Casas/signos contextualizan, no crean por sí solos ontología.
10. Temporalidad activa variables preexistentes; no las crea.
