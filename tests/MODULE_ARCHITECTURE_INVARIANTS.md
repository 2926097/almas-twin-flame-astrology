# Invariantes de arquitectura modular ALMAS

Una release falla si:

- se declara públicamente más de una skill ALMAS en este repositorio;
- un módulo mantiene SemVer público independiente de `VERSION`;
- README, SKILL, VERSION y CHANGELOG describen arquitecturas incompatibles;
- un módulo recalcula silenciosamente valores canónicos producidos por otro;
- el contrato álmico se trata como quinta categoría AF/KA/AG/LG;
- una fuente doctrinal añade puntuación estructural por su mera existencia;
- una hipótesis E se presenta como doctrina C;
- una equivalencia entre tradiciones se afirma sin fuente explícita;
- un caso privado se publica o se usa como ejemplo identificable;
- una regla derivada de un caso pasa a confirmatoria sin definición y test sintético.
