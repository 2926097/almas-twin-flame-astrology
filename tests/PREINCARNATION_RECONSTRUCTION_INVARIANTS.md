# Invariantes · Reconstrucción preencarnatoria

1. La reconstrucción usa ocho etapas: origen, motivo, roles, condiciones de encuentro, tareas individuales, tarea común, cláusulas y mecanismos de cumplimiento.
2. Ninguna etapa posterior puede fabricar retrospectivamente una etapa anterior.
3. El origen se evalúa con modelos competidores; no se fuerza una ontología cuando faltan discriminadores.
4. El motivo del acuerdo debe enlazar con al menos una tarea previa, función o fuente doctrinal identificada.
5. La selección de roles distingue A_EN_B, B_EN_A y CAMPO_COMUN.
6. Las tareas individuales se identifican primero sin usar la sinastría de la otra persona.
7. Las condiciones de encuentro no se deducen de una coincidencia temporal aislada.
8. La tarea común no es la suma de las tareas individuales.
9. Toda cláusula debe tener genealogía interna: motivo/rol/tarea/raíz.
10. Los mecanismos de cumplimiento describen vías funcionales, no desenlaces obligatorios.
11. Cumplimiento no equivale a unión romántica.
12. Ruta alternativa o choice point sólo se usa cuando la doctrina o método correspondiente lo contempla.
13. La rareza astrológica no se convierte en probabilidad de origen, pacto o cumplimiento.
14. Una fuente literaria puede informar genealogía simbólica pero no crear por sí sola una etapa doctrinal.
15. Las doctrinas de tradiciones distintas no se fusionan sin marcar la síntesis como E_PROJECT_HYPOTHESIS.
16. Toda etapa conserva alternativas, contraevidencia, dependencias y robustez.
17. Si el origen queda INSUFFICIENT, las etapas posteriores pueden seguir evaluándose funcionalmente sin elevar el origen.
18. Los datos privados no se publican; los casos reales públicos requieren fuente y procedencia.
