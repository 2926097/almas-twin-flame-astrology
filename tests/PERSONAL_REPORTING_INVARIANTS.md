# Invariantes · Informes astrológicos personales

Una release falla si:

1. El módulo personal se declara segunda skill pública.
2. Su versión pública difiere de VERSION.
3. La narrativa o la maquetación modifican personal_canonical_analysis.
4. El modelo documental incrusta o recalcula valores canónicos.
5. Se inventan hora, huso, lugar o coordenadas.
6. Una hora C/D mantiene sin degradación conclusiones dependientes de ángulos/casas.
7. Una carta de retorno incluye casas sin localidad real documentada.
8. Dracónica, asteroides, estrellas o un atacir aislado crean por sí solos una conclusión estructural.
9. Se presenta E_PROJECT_HYPOTHESIS como C_DOCTRINE.
10. El perfil de informe modifica la conclusión analítica.
11. El router de referencias decide la conclusión en vez de seleccionar corpus.
12. Se declara PDF/X, CMYK o perfil ICC sin conversión/verificación.
13. Se entrega un PDF final sin preflight y revisión visual completa cuando el entorno permite realizarla.
14. Un fixture público contiene datos privados o identificables no publicados.
