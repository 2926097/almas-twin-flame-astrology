# Matriz doctrinal · Lote E · experiencia, uso contemporáneo y ontología

## Tres capas distintas

### 1. Experiencia reportada
Puede incluir:

- reconocimiento inmediato;
- familiaridad;
- sincronías;
- telepatía percibida;
- experiencias energéticas;
- transformación;
- crisis;
- integración de opuestos.

Estas experiencias son **datos fenomenológicos/emic** cuando están documentadas.

### 2. Etiqueta comunitaria
Una persona puede llamar a la relación:

- soulmate;
- twin flame;
- karmic;
- sacred partner.

La etiqueta pertenece a `D_USO_CONTEMPORANEO` salvo que se esté describiendo la doctrina formal de una organización o autor.

### 3. Ontología
Preguntas como:

- ¿comparten origen?;
- ¿son split-soul?;
- ¿existe contrato?;
- ¿hay continuidad de vidas?;
- ¿son twin flames?;

requieren evidencia y discriminadores diferentes.

## Regla

`EXPERIENCIA_INTENSA ≠ ONTOLOGIA_SUPERIOR`

`RECONOCIMIENTO ≠ MEMORIA_LITERAL`

`SINCRONIA ≠ CONTRATO`

`TRANSFORMACION ≠ TWIN_FLAME`

`AUTOETIQUETA_TWIN_FLAME ≠ DIAGNOSTICO_LG`

## Uso de Stokke

El estudio de Stokke se utiliza para documentar que determinadas experiencias se reportan en comunidades que hablan de soulmates y twin flames.

No se utiliza para:

- estimar prevalencia poblacional;
- demostrar telepatía;
- probar vidas pasadas;
- validar twin flames;
- crear una puntuación astrológica.

## Uso de Kwilecki

Kwilecki permite identificar el **soul contract** como una construcción religiosa contemporánea New Age vinculada a planificación prenatal, reencarnación y crecimiento.

No convierte esa construcción en doctrina de Kardec, Cábala, Teosofía o Bailey.

## Consecuencia para informes ALMAS

Todo informe debe distinguir:

A. dato/documento;
B. técnica;
C. doctrina;
D. experiencia o uso contemporáneo;
E. hipótesis ALMAS.

Una experiencia D puede ser compatible con una hipótesis E, pero nunca la confirma por sí sola.
