# Retornos de Júpiter y Saturno · RRA V1

Júpiter y Saturno usan la misma definición longitudinal y requieren ventanas de búsqueda explícitas acordes al ciclo. Paso de muestreo doce horas; ventana documental ±336 horas. No se atribuye compromiso, matrimonio, expansión o cierre a la mera presencia del retorno. Urano, Neptuno y Plutón no son retornos natales ordinarios; cualquier búsqueda secundaria requiere cualificación y efemérides disponibles.
