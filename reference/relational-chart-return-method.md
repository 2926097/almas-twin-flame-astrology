# Retornos de cartas relacionales · RRA V1

El cuerpo transitante alcanza la longitud homóloga de una compuesta, Davison o referencia dracónica fija. La carta aportada debe identificar fuente, método y padres en raíces canónicas. La operación es PROJECT_TECHNIQUE_EXPERIMENTAL, clase E; no se presenta como revolución solar histórica de una relación. La referencia dracónica es simbólica. El subsistema no recalcula ni certifica las cartas derivadas de entrada.
