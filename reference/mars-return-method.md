# Retorno de Marte · RRA V1

Se usa longitud homóloga de Marte, búsqueda completa y estado de movimiento. Ventana ±120 horas, fijada antes de eventos. Marte sólo reactiva una raíz existente: el retorno no implica sexualidad, conflicto, deseo ni acontecimiento. Las mismas reglas de precisión, ubicación y negativos se aplican a todos los propietarios declarados.
