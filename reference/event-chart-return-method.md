# Retornos de cartas de acontecimientos · RRA V1

Un evento documentado puede aportar una referencia EVENT con método y raíces previas. RRA no crea una raíz a partir del evento. Se admiten cuerpos homólogos elegibles, no una recurrencia angular o nodal no habilitada. Precisión insuficiente bloquea factores sensibles. Los controles nulos que exigen mover y recalcular esta carta quedan NOT_EVALUABLE en V1 hasta disponer de una recomputación completa; no se presentan como completados.
