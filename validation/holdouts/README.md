# Holdouts públicos

Este directorio sólo admite:

- controles sintéticos;
- casos reales cuyos datos relevantes ya sean públicos e independientemente verificables;
- metadatos públicos no identificables.

El manifiesto canónico es `validation/holdouts/manifest.json`.

Los holdouts privados no se almacenan aquí. Deben permanecer fuera del repositorio público. Sólo pueden publicarse referencias externas opacas, protocolos preregistrados y métricas agregadas no identificables de acuerdo con `ALMAS_PUBLIC_DATA_ISOLATION_V1`.

La pseudonimización por sí sola no autoriza la publicación de un holdout privado.
