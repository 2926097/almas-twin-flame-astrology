# Changelog

## 1.0.0 — 2026-09-24

First public GitHub release.

- Public renumbering from the internal ALMAS/Twin-Flame Astrology v3.12.1 line.
- Preserves AF/KA/AG/LG structural compatibility model.
- Preserves IEM, IDD/legacy IDE, IRC, IAT, ICC and ICE framework.
- Preserves dependency-aware roots, pillars, counterevidence, null models, ablation and birth-time robustness.
- Preserves synastry, declination, antiscia, composite, Davison, draconic and temporal layers at specification level.
- Makes comparative doctrine and hermeneutic synthesis explicit.
- Expands relational ontology to independent origin/history/function/polarity/modality/phase/viability/reciprocity axes.
- Defines canonical-analysis → report-model → PDF publication contract.
- Adds a dependency-free Python scoring core for pillar aggregation, IEM, IDD and IRC.
- Adds a precomputed-pillar API and `almas-score` command-line interface.
- Adds formal input/output JSON Schemas and reproducible examples for the scoring interface.
- Adds **14 deterministic unit tests** and two GitHub Actions workflows.
- Adds public module/discriminator manifests and preserved v3.12 validation metadata.
- Adds a source-provenance policy and starter machine-readable doctrinal registry.
- Explicitly distinguishes the current public implementation from the still-pending verified import of the historical astronomical, evidence-extraction, Monte Carlo/ablation and report-rendering engines.
