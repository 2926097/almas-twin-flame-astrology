    Contrato de aislamiento

    El visor no recalcula posiciones, índices, puntuaciones, evidencias ni ontología; la ejecución Python local usa únicamente el motor original. SHADOW/NO-GO de Atacires permanece inalterado. El visor no demuestra hipótesis metafísicas ni crea un informe analítico.

    Conexión experimental al núcleo ALMAS

    Una solicitud de solo lectura al motor Python ejecuta exclusivamente el ejemplo público de pilares precalculados. No se transmiten datos personales, cartas ni el archivo JSON local. La respuesta no es canonical_analysis y no habilita M30.

    Validación M30/M31 — caso sintético
    El servidor genera un canonical exclusivamente sintético, comprueba su JSON Schema oficial, ejecuta M30 y construye M31. Solo se devuelven el estado de reportabilidad, el fingerprint y los identificadores de secciones. No se transmite tu archivo importado, ningún dato natal ni puntuaciones.
