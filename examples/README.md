# Examples

The default examples in this directory are **synthetic**.

Their values are artificial fixtures designed to exercise the public interfaces and regression tests. They do not represent, approximate or encode an identifiable private relationship, birth chart or biographical history.

If a real-world example is added in the future, it must be placed in a clearly identified public-case corpus and satisfy `docs/PUBLICATION_POLICY.md`: the underlying data must already be public, independently verifiable and cited.
