# Plan adversarial sintético del discriminador ontológico · Paso 11

## Objetivo

Intentar romper los firewalls de identificabilidad de ALMAS con entradas hostiles reproducibles antes de diseñar la matriz metamórfica formal.

## Superficies atacadas

### Inflación

Se inyectan decenas o cientos de observaciones L1/L2. La cantidad no puede sustituir el nivel de validación. La salida confirmatoria debe conservar todos los modelos cuando no existe L3 admisible.

### Dependencia

Se replica una misma raíz L3 bajo múltiples identificadores. La deduplicación por root_key debe conservar una sola raíz efectiva.

### Conflicto

Se fuerza evidencia incompatible dentro de una misma raíz y se construye un ciclo global de exclusiones. Ambos escenarios deben degradar identificabilidad, no fabricar una categoría específica.

### Ausencia y datos insuficientes

NOT_EVALUABLE y minimum_data_evaluable=false se usan como ataques para comprobar que ausencia de información no actúa como contraevidencia.

### Contaminación narrativa

Se añaden autoetiqueta, runner/chaser, sincronías, intensidad subjetiva, sensación de destino, rareza astrológica y afirmaciones temporales. M21 no debe transmitir ninguna de esas variables al motor ontológico.

### Falsificación L3

Se intenta reutilizar un promotion_ref con:

- par no autorizado;
- root_key fuera de familia;
- registro de validación incompleto.

La ejecución debe rechazar esas entradas antes de que alcancen el motor confirmatorio.

## Criterio de éxito

El Paso 11 se considera superado cuando toda la batería adversarial pasa en Python 3.10 y 3.12 junto con el contrato público.

No se promociona ningún discriminador por superar estos tests. Son controles de seguridad metodológica, no evidencia de validez externa.

## Fuera de alcance

El Paso 12 realizará las pruebas metamórficas formales: permutaciones de orden, invariancia por reordenación de pares, transformaciones semánticamente equivalentes, idempotencia y otras relaciones metamórficas.
