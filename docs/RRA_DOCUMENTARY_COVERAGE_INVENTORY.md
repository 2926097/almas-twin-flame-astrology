# RRA · Inventario documental activo

Actualizado el 3 de octubre de 2026. Estado: **PARTIAL_INVENTORY_NOT_CONTROL_READY**. Por instrucción del usuario se retira P05 y se sustituye por P08, Franklin–Eleanor Roosevelt. El acta retirada y sus testimonios asociados dejan de formar parte del inventario activo. La sustitución es anterior al cálculo de resultados y se conserva en el historial; no se borra la historia de Git ni se rehabilita el candidato retirado para el holdout.

El inventario comprende ocho unidades o recursos de P06, P07 y P08: dos descripciones documentales de Kahlo–Rivera, tres recursos editoriales o de acceso de Einstein–Marić y tres páginas documentales o biográficas Roosevelt. No existen manuscritos originales leídos, pasajes primarios transcritos activos o fechas discrepantes pendientes en este inventario. Esa ausencia de conflictos activos no acredita exactitud cronométrica ni autenticación de todas las fuentes.

Para Roosevelt, la Biblioteca Presidencial FDR publica una descripción y una copia del certificado matrimonial del 17 de marzo de 1905 en Nueva York. Se han leído la descripción y las biografías, y abierto el enlace a la imagen; el cotejo visual integral no se certifica como completado. Las biografías dan nacimiento de Franklin el 30 de enero de 1882 en Hyde Park y de Eleanor el 11 de octubre de 1884 en Nueva York. Los pasajes no proporcionan horas natales. La fecha de boda se eligió por disponibilidad del presidente Theodore Roosevelt; ese mecanismo calendario se registra como límite para diseñar controles. No se imputan horas ni se producen instantes UTC.

Se conservan para Kahlo–Rivera las descripciones del reloj matrimonial y de una carta, sin lectura original certificada. Para Einstein–Marić se conserva el método editorial, la descripción del volumen 5 y la página pública del portal, sin acceso verificado a cartas individuales. La descripción de un fondo, una biografía y el silencio de una carta no demuestran ausencia de todos los eventos relacionales del protocolo.

Cada unidad mantiene identificador, vínculo, localizador, acceso realizado, soporte leído, afirmaciones y alcance. Todos los campos de controles negativos permanecen falsos y no hay controles admitidos. Se conserva un codificador; falta inventario exhaustivo, denominador de cobertura y acuerdo entre codificadores. La cohorte y el runner confirmatorio continúan pendientes.

El script `scripts/validate_rra_documentary_inventory.py` comprueba recuentos, referencias, componentes reconstruidos desde personas, conflictos y ausencia de promoción confirmatoria. Las pruebas de discrepancias usan datos sintéticos y no dependen del candidato retirado. Un historial de sustitución debe excluir el identificador retirado y señalar un sustituto activo; no autoriza reutilizar el retirado en el holdout. El workflow de contrato público ejecuta estas comprobaciones. El validador no autentica fuentes ni evalúa eficacia temporal.
