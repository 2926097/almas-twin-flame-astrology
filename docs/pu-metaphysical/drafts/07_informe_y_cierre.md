# Borrador de informe y cierre

El informe presentará pregunta, fuentes verificadas y huecos, matriz PU_D, red de comparadores, firma preregistrada, distancias, márgenes, calidad, alternativas y limitaciones. Mostrará qué componente es dato, técnica, doctrina, uso contemporáneo o hipótesis. La síntesis no seleccionará el modelo con mayor IEM ni elevará origen por intensidad o bajo IRC.

El cierre técnico deberá adjuntar estado de pruebas, archivos, commit, limitaciones y evidencias de ejecución. Se distinguirá IMPLEMENTED_EXPERIMENTAL de VALIDATED. Los borradores metodológicos se completan como documentos utilizables; firmas externas, cohorte real y resultados empíricos no se inventan.
