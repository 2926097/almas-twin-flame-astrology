# Provenance

Public version `1.0.0` is an editorial renumbering of the mature ALMAS/Twin-Flame Astrology internal line.

Documented internal reference point: **v3.12.1**. That line added a mandatory hermeneutic layer over the frozen v3.12.0 structural formulas and preserved the calculation → evidence → validation → ontology → interpretation → report architecture.

The public release intentionally presents a clean semantic-version baseline. Future public changes should use SemVer:

- PATCH: implementation/documentation correction that does not change frozen methodology.
- MINOR: backward-compatible new module, source layer or optional technique.
- MAJOR: changed ontology, scoring formula, gate, independence rule or canonical contract.

This repository should not claim binary identity with any historical private ZIP unless that exact archive is later imported and hash-verified.
