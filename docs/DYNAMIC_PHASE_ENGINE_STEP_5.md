# ALMAS · Paso 5: motor documental y conductual de fases

`evaluate_dynamic_phase_event` recibe un evento fechado, código de conducta explícito, actor, contexto, referencias de evidencia y contraevidencia. No interpreta texto libre: el código debe haber sido asignado como metadato humano o por un extractor validado externamente. Esta primera versión reconoce únicamente reconocimiento explícito, afirmación de límite, pausa mutuamente acordada, reanudación bilateral y terminación explícita. Los demás códigos devuelven `NOT_EVALUABLE` sin fase candidata.

Para actos individuales exige evidencia directa atribuible al actor. Para pausa y reanudación relacional exige evidencia documental o conductual directa de A y B; un informe secundario o una sola fuente deja el candidato `INSUFFICIENT`. Contraevidencia registrada lleva a `CONTRADICTED` y no cambia `phase_after`. Cuando la regla está satisfecha, el evento produce `SUPPORTED`; no dice nada sobre estados internos, categorías espirituales, reciprocidad afectiva o predicción. Un estado previo se conserva ante eventos sin soporte suficiente.

La fuerza de evidencia es una clase descriptiva de procedencia, no una probabilidad ni un score. `phase_before`, `phase_candidate`, `phase_after`, referencias y estado se devuelven por separado. El módulo no accede a cartas, tránsitos, doctrinas ni texto interpretativo. La integración en el canonical se abordará después de estabilizar los criterios de surrender, awakening y secuencias. Las entradas y salidas tienen schemas cerrados y casos sintéticos que comprueban fuentes unilaterales, contraevidencia, códigos desconocidos y ausencia de mutación.
