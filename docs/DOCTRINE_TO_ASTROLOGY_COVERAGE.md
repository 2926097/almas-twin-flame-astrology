# ALMAS · Cobertura doctrina → astrología

**Versión:** 1.10.0

La existencia de un concepto doctrinal no obliga a crear una regla astrológica.

## Estados

- **MAPPED**: existe una operacionalización astrológica explícita y trazable.
- **CONTEXT_ONLY**: el concepto aporta contexto histórico, académico o fenomenológico.
- **BOUNDARY_ONLY**: el concepto existe para impedir una inferencia indebida.
- **TECHNIQUE_CONTEXT_ONLY**: documenta una técnica sin crear por sí sola una variable metafísica.
- **PROJECT_INTERNAL**: concepto interno gobernado por otros schemas/registros.
- **NOT_OPERATIONALIZED**: no existe aún una traducción astrológica validada o preregistrada.

## Regla metodológica

Que una doctrina hable de Mónada, zivug, contrato, misión, reencarnación o pares de almas no autoriza automáticamente a asignarle una firma astrológica.

Toda operacionalización debe declarar:

1. fuente doctrinal;
2. variable metafísica;
3. clase de operacionalización;
4. indicadores astrológicos admisibles;
5. inferencias inadmisibles;
6. dependencia entre técnicas;
7. estado de validación.

Los conceptos no operacionalizados permanecen doctrinales/contextuales hasta que exista una regla reproducible.
