# Fuentes y techo inferencial

El registro empaquetado `vedic-source-anchors.json` vincula los IDs de las fórmulas con pasajes inspeccionados. Rao (2000) se clasifica P4, autor identificado con método. Sus reglas se implementan con perfiles explícitos; no se declara haber cotejado una edición crítica sánscrita. Sus usos natales no justifican automáticamente usos relacionales cruzados.

La documentación primaria de Astrodienst respalda la interfaz y las convenciones del proveedor, sin validar interpretaciones astrológicas. La comparación contra los flags Swiss es interna al mismo motor. El ejemplo 29 también aparece en las pruebas de PyJHora, SHA `48e57d29b47a3143519910a24866758116467485`, `src/jhora/tests/pvr_tests.py`, función `bhava_arudha_tests_1`; esta coincidencia es documental y no un segundo cálculo astronómico independiente. No se copió código de PyJHora.

La genealogía histórica de Bhrigu Bindu, las tablas completas de Aṣṭakūṭa, Prāṇapada y Yogatārās carecen de verificación suficiente para esta release. Los datos ausentes conservan un estado explícito; la geometría de Bindu es reproducible, pero su interpretación permanece experimental.
